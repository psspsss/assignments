5G NR PBCH Structure

Physical Broadcast Channel in Synchronization Signal Block (SSB)

Overview

What is PBCH?

The Physical Broadcast Channel is a critical component of the 5G New Radio (NR) downlink. It sits within the Synchronization Signal Block (SSB) and carries the Master Information Block (MIB), which provides the User Equipment (UE) with the essential parameters needed to access the network.

PBCH Technical Specs

Parameter Value
Frequency Span 20 RBs (240 Subcarriers)
Time Span 3 OFDM Symbols (within SSB)
Periodicity Default 20ms
Payload MIB (Master Information Block)
Modulation QPSK
Reference Signal DMRS (embedded in PBCH)

How It Works

  1. MIB Generation: The network generates the Master Information Block (Frame number, subcarrier spacing, etc.).
  2. Encoding: MIB is CRC attached and Polar Encoded for robustness.
  3. Mapping: Data is mapped to the Resource Grid. Note that DMRS (Demodulation Reference Signal) is interleaved with PBCH data to help the phone decode the signal.
  4. Transmission: The SSB (containing PBCH) is broadcasted periodically (default 20ms) to allow phones to sync.

Timeline & Periodicity

PBCH is not continuous; it is transmitted in bursts. This timeline shows the periodic nature of the Synchronization Signal Block.

Key Insight: Unlike LTE where reference signals were always on, 5G uses an "always off" design. PBCH is only sent during these specific SSB bursts to save energy and reduce interference.
