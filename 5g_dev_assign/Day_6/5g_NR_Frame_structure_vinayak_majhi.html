5G NR Time Domain Structure

Radio Frame

10 ms

The largest time unit in 5G NR. Each frame contains 10 subframes. Frame duration is always fixed at 10ms.

Subframe

1 ms

Each subframe is exactly 1ms. A subframe contains 1, 2, 4, 8, or 16 slots depending on the numerology.

Slot

14 Symbols

The basic scheduling unit in 5G NR. Each slot contains 14 OFDM symbols (12 for extended CP).

OFDM Symbol

Variable

Duration depends on SCS. Contains CP + useful symbol. Formula: 1/(14 × 2^μ) ms.

Resource Block (RB)

12 SC

Smallest frequency allocation. One RB spans 12 consecutive subcarriers in frequency domain.

Resource Element (RE)

1x1

One RE = 1 subcarrier × 1 OFDM symbol. Carries one modulation symbol.

// Frame Structure Logic

Slots_per_Frame = 10 × 2^μ
Slot_Duration = 1 / 2^μ ms
