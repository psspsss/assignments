Key Characteristics

UM Mode Overview

Unacknowledged Mode (UM) provides efficient data transfer with segmentation but no retransmissions. The architecture flows from top-to-bottom on the transmitter and bottom-to-top on the receiver.

Transmitting Flow:

  1. Generate RLC Header & Store
  2. Segmentation & Header Modification
  3. Add RLC Header

Receiving Flow:

  1. Reception Buffer (Buffer & Reorder)
  2. Remove RLC Header
  3. SDU Reassembly

📤 Transmit Operations (Section 5.2.2.1)

Transmission Process

UMD PDU Formation

When submitting a UMD PDU to lower layer, the transmitting UM RLC entity shall:

IF UMD PDU contains segment of RLC SDU: SET SN of UMD PDU to TX_Next IF UMD PDU contains segment that maps to LAST BYTE of RLC SDU: INCREMENT TX_Next by one

TX State Variable

TX_Next:
Holds value of SN to be assigned for next newly generated UMD PDU with segment. Initially set to 0.
