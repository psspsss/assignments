Understanding RLC Segmentation

What is RLC Segmentation?
RLC (Radio Link Control) segmentation is a process in cellular networks where large data packets (SDUs - Service Data Units) are broken down into smaller segments (PDUs - Protocol Data Units) for efficient transmission over the air interface.

Segmentation Info (SI) Field

The SI field is a 2-bit field that indicates the type of segment contained in the RLC PDU:

Binary Value Description Use Case
00 Complete SDU Data field contains all bytes of an RLC SDU (no segmentation needed)
01 First Segment Data field contains the first segment of an RLC SDU
10 Last Segment Data field contains the last segment of an RLC SDU
11 Middle Segment Data field contains neither the first nor last segment of an RLC SDU

Segment Offset (SO) Field

Length: 16 bits (2 bytes)

Purpose: The SO field indicates the position of the RLC SDU segment in bytes within the original RLC SDU. It tells the receiver where this particular segment fits in the original message.

Example: If SO = 0, this is the start of the message. If SO = 100, this segment starts at byte 100 of the original message.

Real-World Example: WhatsApp Message

Imagine sending this WhatsApp message:

"Hey! Just wanted to let you know that I'll be arriving at the airport around 3 PM tomorrow. Can you pick me up? Thanks!"

If the maximum PDU size is 50 bytes, this 120-byte message would be segmented into:

  • PDU 1 (SI=01, SO=0): First 50 bytes - "Hey! Just wanted to let you know that I'll be ar..."
  • PDU 2 (SI=11, SO=50): Next 50 bytes - "riving at the airport around 3 PM tomorrow. Can y..."
  • PDU 3 (SI=10, SO=100): Last 20 bytes - "ou pick me up? Thanks!"

RLC Segmentation Architecture

Segmentation Flow

Key Points:
• SDU (Service Data Unit) is the original data packet from upper layers
• Maximum PDU size determines how the SDU is segmented
• Each PDU includes a header with SI and SO fields (for segments)
• Receiver uses SI and SO to reassemble the original SDU
• First segment (SI=01) has SO=0, subsequent segments increment by segment size
